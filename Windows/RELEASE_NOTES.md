# 伊娃桌面宠物 · Windows 13.3.2

CPU 温度口径与眼睛动作切换修复版。

## 本次修复

- CPU 温度默认由“所有传感器最高值”改为“核心平均温度”。
- Intel 优先读取 LibreHardwareMonitor 的 `Core Average`，AMD 优先读取 `CCDs Average (Tdie)`；缺失时平均真实核心传感器。
- 旧版本的默认最高温度设置会自动迁移为核心平均模式；仍可在设置中选择“最高热点温度”。
- 动作切换时不再同时叠加新旧两组眼睛弧线，每只眼睛只绘制一条连续插值路径。
- 开心眼切换睡眼时使用短暂柔和眨眼跨越方向，移除端点黑点和水平残线。

## 主要功能

- 待机、巡航、开心、玩耍小火箭、休眠五种连贯动作。
- 普通形态和小火箭均可直接拖动，拖动方向与尾气即时变化。
- CPU/GPU 性能卡片支持四向位置、透明背景、系统字体、字号、颜色与透明度。
- 三种防护罩、玻璃悬浮光池、六种情绪、陪伴文案和提醒。

## 验证

- Windows Server 2025 / Python 3.13 云端构建。
- Ruff 静态检查与 21 项自动测试。
- PyInstaller one-folder 打包及完整启动、干净退出测试。
- Release 提供 `.sha256` 校验文件。

当前发布包为 Windows x64、未进行商业代码签名。首次运行若出现 Microsoft Defender SmartScreen 提示，请核对下载来源与 Release 中的 SHA-256。

# 伊娃桌面宠物 · Windows 13.3.0

首个经过本仓库统一审查、测试和可复现构建的 Windows 版本。

## 主要功能

- 待机、巡航、开心、玩耍小火箭、休眠五种连贯动作。
- 点击随机切换状态；普通形态和小火箭均可直接拖动。
- 小火箭沿连续 8 字轨迹飞行，尾气和方向随拖动即时变化。
- 五种动作对应眼睛与低饱和胸部核心光色，无旧图闪现。
- 三种防护罩、玻璃悬浮光池、六种情绪和陪伴文案。
- CPU/GPU 占用率和温度卡片，支持四向位置、透明背景、字体与颜色。
- 每日/间隔提醒、开机启动、单实例与自适应明暗托盘头像。

## 本次审查修复

- 修复源码包 `assets/assets` 嵌套导致的资源加载失败。
- 移除应用全程管理员启动；只有主动启用 CPU 温度时才请求 UAC。
- 使用 Win32 原生坐标实现 1:1 拖动，并缩短跨屏绘制保护期。
- 修复玩耍状态没有火箭、状态切换闪图、眼睛瞬间跳变的问题。
- 修复修改设置后状态机与性能采样仍使用旧配置的问题。
- 修复电脑睡眠恢复后每日提醒漏发，以及间隔提醒启动即弹出的问题。
- 增加 AMD/Intel GPU 占用率降级路径；无法可靠读取的温度明确显示不可用。
- 加入构建期高清纹理，避免第一次启动执行昂贵的逐像素处理。

# 伊娃桌面宠物 · Windows 13.3.1

CPU 温度与性能卡片字体设置修复版。

## 主要功能

- 待机、巡航、开心、玩耍小火箭、休眠五种连贯动作。
- 点击随机切换状态；普通形态和小火箭均可直接拖动。
- 小火箭沿连续 8 字轨迹飞行，尾气和方向随拖动即时变化。
- 五种动作对应眼睛与低饱和胸部核心光色，无旧图闪现。
- 三种防护罩、玻璃悬浮光池、六种情绪和陪伴文案。
- CPU/GPU 占用率和温度卡片，支持四向位置、透明背景、Windows 系统字体、8–18 pt 字号与颜色。
- 每日/间隔提醒、开机启动、单实例与自适应明暗托盘头像。

## 本次修复

- 修复普通权限下先安装温度驱动、尚未进入 UAC 就提前失败的问题。
- PawnIO 驱动现在由获得管理员权限的独立助手安装，主应用不需要以管理员身份运行。
- 温度助手首次成功采样后立即清除失败缓存，不再继续显示两分钟“不可用”。
- 设置界面改用 Windows 系统字体选择器，所选字体会真实写入并应用到性能卡片。
- 增加 8–18 pt 字号设置，窗口和卡片空间会随字号同步调整。

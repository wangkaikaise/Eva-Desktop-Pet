# 伊娃桌面宠物 Windows 源码说明

版本：13.3.0
技术栈：Python 3.13、PySide6/Qt 6、Win32、PyInstaller

这个目录包含可复现的 Windows 源码、视觉素材、测试、依赖清单和构建脚本。资源目录必须
保持为 `assets/character`、`assets/effects`、`assets/icons` 等单层结构，不能再嵌套一个
`assets`，否则开发运行和打包都会找不到素材。

## 关键实现

- 角色使用构建期生成的 `eva-character-runtime-v15.png`，避免首启逐像素处理。
- 动态眼睛、胸部核心、光池、防护罩、尾迹和性能卡片均在运行时分层绘制。
- 玩耍状态绘制 SVG 小火箭，与机器人以 0.8 秒交叉淡化；进入和退出都不显示旧中间图。
- 直接拖动通过 Win32 `SetWindowPos` 更新窗口，不对鼠标位置做插值。
- 设置引用会同步绑定到状态机和性能采样器，修改动作速度、情绪和监控项后立即生效。
- 关闭性能项后不再采样对应传感器；CPU 温度扩展默认不提权。

## 质量检查

```powershell
.venv\Scripts\python -m ruff check main.py eva_window.py metrics.py reminders.py settings.py settings_dialog.py state_machine.py tests
.venv\Scripts\python -m pytest
```

发布构建统一运行 `scripts/build_windows.ps1`，不要手工复制未知来源的 DLL 或驱动。
